Overall Course Reflection

Throughout this semester in Data Structures and Algorithms, I have grown a lot in my ability to solve problems. At the start, I only knew basic programming ideas. Now I can build and use more complex algorithms. This change was hard, but it felt great to achieve. This portfolio shows my journey in learning how data is organized and how to work with it in fast and smart ways. I learned that writing clean code that is easy to fix and update is just as important as making the code work. I also learned how choosing the right data structure, like arrays, lists, stacks, queues, or trees, can change how fast a program runs. And I learned how algorithms, like searching and sorting, help solve problems step by step. I look forward to using these skills in my future career in Networking and Cybersecurity, where organizing data and solving problems quickly and safely really matters.
